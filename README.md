# real-time-stock-predictor

미국 주식 가상거래·과거 실시간 시뮬레이션 연구 작업 공간입니다. 키움 REST API를 쓰고, 실제 주문과 레버리지는 쓰지 않습니다.

- 처음 받으면 `python restore_archives.py --reports`를 실행해 데이터·신호·결과를 복원하세요.
- 작업 맥락, 규칙, 현재 상태는 [CLAUDE.md](CLAUDE.md)에 정리돼 있습니다.
- Kaggle 실행용 코드는 공개 저장소 [yeomin1024/stock](https://github.com/yeomin1024/stock)에 있습니다(`kiwoom_autotrader.py`, `kaggle_runner_onecell.py`).
